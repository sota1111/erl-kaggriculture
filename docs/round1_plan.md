## 0. 先に測るもの — レーティングの収束時間

**未知数のまま population を回すと、全ての比較が無意味になる。**
2026-09-03 に再提出した moon-198(submission `55971967`、受理時 600.0)の
**レーティング上昇曲線を 24〜48 時間追跡する**。測る項目:

1. 600 から収束値までに要する時間(および対戦エピソード数)。
2. 収束値そのもの。**これが 8/3 の 2543.4 に対する現フィールドの再測定値であり、
   ラウンド1 の親スコアになる。**
   → **測定済み(2026-09-03 02:32、13エピソード、967.0)。2543.4 は再現しなかった。**
   同格帯(828〜1013)で 2勝4敗。現在の実力は 900〜1100級と推定される。
   詳細と、この結果が参戦判断に与えた訂正は `results/baseline/rating_convergence.md`。
3. 同時に複数の提出をアクティブに保てるか、LB に出るのはどれか。

**この3点が埋まるまでラウンド1 の候補は提出しない。**
NEDO ラウンド1 の教訓(単一 run の比較で軸の効果を語ってはならない)と同じ理由で、
**収束前の値で候補を並べてはならない。**

## 2. ゲート(機械的、事前確定)

### 2.1 ローカル足切り(昇格判定ではない)

以下を**1つでも**満たしたら提出しない。これ以外の理由でローカル値を使って
順位付け・昇格判定をしてはならない(`docs/competition_brief.md` §5.1)。

- 12 seed × 両席のいずれかで例外・タイムアウト・`DONE` 以外で終了する
- 1ターンの最悪実行時間が 0.5 秒を超える(制限 1 秒に対する安全率2)
- 内蔵 `starter` に対して所持金で負ける seed がある
- `tools/validate_submission.py` が FAIL

### 2.2 実 LB ゲート(唯一の昇格判定)

- 足切りを通った個体を、**収束時間を空けて**順に提出する(5回/日)。
- **基準線はメダルライン(銅 1957.2)であり、moon-198 ではない。**
  moon-198 の収束値は 900〜1100級にすぎず、**それを超えただけでは何も達成していない。**
  収束後レーティングを銅ラインとの距離で評価する。
- ラウンド2 の親 = **収束後レーティング上位3個体**。同値は提出が早い方を優先。
  この規則は結果を見る前に確定しており、事後に変更しない(v0.4.7 の反省)。

## 3. 提出スケジュール(レーティング収束が律速)

| 日 | 内容 |
| --- | --- |
| D0(9/03) | moon-198 再提出(**完了**)。収束曲線の観測開始 |
| D1–D2 | 収束時間・収束値の確定。並行して 8個体をローカルで生成・足切り |

> その後に弱い個体を出し続けたために 3,251 位まで落ちた——**メダルはアクティブな
> 提出に対して付く。**締切24時間前は新規提出を停止し、最良個体を置いておく。

## 4. 本ラウンドで答える問い

1. **レーティングはいつ収束するか。**(全ての測定の前提)
2. **公開解 moon-198 の上積みは取れるか。** `baseline` 系 4体のうち何体が収束値を超えるか。
3. **白紙から公開解に届くか。** `scratch` 系 4体の到達点。ERL の研究価値はここにある。
4. **P3 優位はこの問題クラスで成立するか。** NEDO では成立しなかった。
5. **fable は opus と互角か。** 互角ならラウンド2 以降の population を fable で厚くできる。

## 5. 撤退条件(2026-09-03 改訂)

**旧条件は「moon-198 を保持すれば銅圏の見込みがある」を前提にしていたが、
その前提は再測定で否定された**(moon-198 は 900〜1100級、銅ライン 1957.2 に遠く届かない)。
保持は撤退先として機能しない。改訂版:

- **D7 時点で最良個体が 1,500(上位20% = 1524.9 相当)に届かない場合**、
  銅ライン到達の見込みが薄いと判断し、ラウンド2 の規模を縮小して NEDO(10/19)へ資源を寄せる。
- **D7 時点で 1,500 を超えている場合**、ラウンド2 を全力で起動する。
  銅まで残り 450 ポイントで、進化1世代の射程内にある。
- いずれの場合も、**締切24時間前に最も収束レーティングの高い個体をアクティブにして固定する**
  規約(§3)は維持する。
