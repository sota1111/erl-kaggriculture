## 1. effort 軸は支配的。NEDO の知見は転移しなかった

| | bank 平均 |
| --- | ---: |
| low(n=3) | 18,547 |
| **xhigh(n=2)** | **70,611** |
| **差** | **52,064** |
| low アーム内のばらつき | **3,234** |

**差はばらつきの16倍。**ノイズでは説明できない。

**NEDO ラウンド1 では `effort=low` は 2体とも 12/12 でゲート未達=使用不能だった。**
本コンペでは low も**完走する個体を作れている**(破綻ゼロ、契約 PASS、starter に全勝)。
ただし**水準が基準線の 10〜15% にとどまる。**「使えない」ではなく「弱い」。
**v0.4.6 で確認した『effort 軸はコンペ依存』が、3例目として再現した。**

## 2. P1 / P3 の差は、この断面では読めない

| effort | P1 の bank | P3 の bank | 差 |
| --- | ---: | ---: | ---: |
| low | 18,018 / 14,784 | 22,840 | +6,440(対 P1平均) |
| **xhigh** | **70,975** | **70,246** | **-729** |

xhigh では **差 729 で、low アーム内のばらつき 3,234 より小さい。実質ゼロ。**
low では P3 が +6,440 だが n=1 対 n=2 で、ばらつきの2倍しかない。

**NEDO で「P3 優位は転移しなかった」と観測したのと整合する。**
表形式コンペの「P3 が構造発見のゲート(22/22 P3 / 0/14 P1)」は、
**シミュレーション上でアルゴリズムを書く問題クラスでは 2 コンペ連続で成立していない。**

### ただし P3 は「出来上がり方」を変えている

同じ到達点でも報告の質が違う。P3(`r1-11`)は設計判断ごとに数値を出している:

- 苺需要係数 15 対 3 → 12-seed 平均 62,654 → **65,021**
- 予備の coop 2枠・pasture 3枠を残す 対 残さない → 4-seed 平均 **57,170 対 51,523**
- 肥料5個の留保 → 12-seed 平均 65,479 → **68,048**
- 単作の実測:自己対戦で WHEAT は片側 1,068個 販売後も終値 19、CARROT は片側 475個 で崩れる
- 棄却:店舗連動で家畜を増やす案(固定小群 62,654 対 全畜産連動 55,421、牛乳のみ 57,944)

P1(`r1-09`)も家畜・肥料・希少性待ちを 12-seed で棄却しているが、係数レベルの
比較値は残していない。**P3 は結果ではなく過程に効いている**可能性がある。
これは bank / margin のどちらでも捉えられない差であり、**現在の指標では測れていない。**

## 3. 2つのローカル指標が、いまだに順位で食い違う

| | bank 順 | マージン順 |
| --- | --- | --- |
| xhigh の P1 / P3 | **P1 > P3**(+729) | **P3 > P1**(+7,728) |
| low の r1-13 / r1-14 | **r1-14 > r1-13** | **r1-13 > r1-14** |

**同じ2個体の強弱について、2つの指標が逆を言う組が2つある。**
どちらが実LBの順位を保存するかは未検証であり、**昇格判定にローカル順位を使えない。**
`docs/round1_plan.md` §4.2 の較正(n=16 で Spearman を取る)が必要な理由がこれである。

## 4. 全個体が同じ壁の手前にいる

**5個体すべてがプール9体中8体に 0/24 で全敗**し、勝率はどれも 24/216 = 11.1%。
最良でも基準線の 47%。**まだ勝負の領域に入っていない。**

## 5. 運用上の欠陥

- **`agent_submission.json` のスキーマが守られない。** `r1-11` は `rejected_hypotheses` と
  `local_eval` を配列/オブジェクトではなく**文字列**で出した。集計時に文字単位で
  イテレートして初めて気づいた。**`validate_submission.py` に型検査を追加すべき。**
- **`r1-13` は基準線を表示しない旧ツールで走った。**同条件の `r1-14` を追加して解消済みだが、
  **道具を変えたら、それ以前の個体は比較から外すこと。**
