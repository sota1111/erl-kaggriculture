# 参戦判断 — `kaggriculture` か `biohub-cell-tracking` か(2026-09-03)

**結論: `kaggriculture` に参戦する。`biohub-cell-tracking-during-development` は見送る。**

判断基準はユーザー指定の「**メダルが取れる確率が高い方**」。以下はすべて 2026-09-03 に
Kaggle API とフル LB スナップショットから取得した実測値であり、印象ではない。

## 2. 決め手 — 銀圏の個体を既に作ってあり、それを失効させていた

提出履歴を全件確認したところ、`kaggriculture-claude` の champion **moon-198**
(`main.py` sha256 `7c5a4a2a…`、198行、SOT-2368/2417)が **2026-08-03 に実 LB 2543.4**。
現在の盤面に当てはめると **165位 = 上位 2.23%(銀圏)**、銅ライン 1957.2 に対し 585 の余裕。

**このコンペの LB は「最高スコア」ではなく「現在アクティブな提出」を表示する。**
自ベスト 2543.4 がありながら順位が 3,251 位(897.2)であった事実がその証拠であり、
2543.4 は失効していた。8/3 以降 claude リネージを止めて gpt リネージだけを回した結果、
gpt は同時期 104〜264、最終 897.2 で止まっている
——**NEDO ラウンド1 の「claude 系と codex/sol 系の分布が重ならない」が本コンペでも再現している。**

## 3. Biohub を採らない理由

- 自ベスト 0.810 から銅 0.934 まで **1,922 チーム分**の差。`biohub-claude` は 113 PR・
  9 サイクルを回して 0.509 → 0.810、直近サイクルは全 REJECT で頭打ち。
- **LB が公開ノートブックの台地で埋まっている。**同一スコアに積み上がったチーム数:

  | スコア | チーム数 | ブロック先頭順位 |
  | ---: | ---: | ---: |
  | 0.9360 | 132 | 82 |
  | 0.9350 | 79 | 214 |
  | 0.9340 | 57 | 293 |
  | 0.9330 | 89 | 350 |
  | 0.9150 | 150 | 861 |

  **銅の境界(302位 / 0.934)が台地の内側にある。**締切までに台地は銅ラインの下へ
  押し下げられるため、**メダルには公開解を上回る必要がある**が、現在地は公開解より 0.126 下。
  同着ブロックは提出時刻順で末尾に付くため、いま丸ごと採用しても終盤には抜かれる。
- kernels-only の 3D 光シート動画に対し、手元の GPU は RTX 3080 Ti 1枚(12GB)。残り 26 日では届かない。

## 4. 見送りに伴って引き受けたリスク(既知、対処込み)

1. **スコアは相対レーティング。** 600 が新規提出の出発点かつノイズ床
   (SOT-2379: soil は実 LB で 600 に張り付いた)。8/3 の 2543.4 は当時のフィールドに対する値で、
   現在の首位は 2961.8 まで伸びている。→ **moon-198 の再提出自体を再測定として最初に実施した。**
2. **ローカル評価が信用できない。** SOT-2417 で replay-league が実 LB の順序を反転させることが
   実証済み(実 LB では moon-198 ≫ soil、league では逆)。較正は `CALIBRATED = False` で終了。
   IEEE-CIS の ρ=-1.000、NEDO の採点系欠陥と**同型**の失敗。
   → **昇格判定は実 LB のみ。**予算は 5回/日。
3. **baseline の出自は公開カーネルの蒸留**であり独自成果ではない(正本 §7)。
   **ERL の上積みはここからの差分として測る。**
4. **NEDO(10/19、賞金1500万円)との資源競合はない。** CPU のみ・GPU 不要・ループは共通。
   ただし締切は NEDO より先に来る(9/30)。

## 6. 訂正(2026-09-03 02:32)— §2 の前提は成立しなかった

**「moon-198 は銀圏の個体である」という決め手は、再測定によって否定された。**
測定の詳細は [`results/baseline/rating_convergence.md`](../results/baseline/rating_convergence.md)。

- 同一バイト列の再提出は 13 エピソードで **967.0**。相手平均レーティング 828 に対し 7勝4敗で、
  **同格帯(828〜1013)では 2勝4敗**。2500級の個体なら 900 帯を圧倒するはずだが、していない。
- **コンペ開始は 2026-07-30 16:15 UTC。2543.4 は開始4日目、54エピソードすべてが 08-03 の
  7時間以内に消化された値である。**
- moon-198 の蒸留元カーネルの作者 prvsiyan は 9/02 に提出しているアクティブなチームで、
  現在 **1,084位 / 1,685.7 と銅ラインを下回る**。方策族ごとフィールドに置いていかれた。

**したがって §1 の「見積り(銅)70〜80%」は撤回する。**
レーティングは相対値であり、**8月のレーティングを9月の分布に載せた対応づけ(2543.4 → 165位)は
無効**だった。§4-1 でこれをリスクとして挙げながら、確率見積りにはその仮定を組み込んだまま使った。
**これが本判断の最大の誤りである。**

### 再見積り

moon-198 の現在の実力は **900〜1100級**。銅 1957.2 までは 2,500チーム分あり、
ERL での上積みが必須。**銅の獲得確率は 30〜40%。**

### それでも kaggriculture を選ぶ理由(根拠の差し替え)

| 根拠 | 状態 |
| --- | --- |
| ~~既に銀圏の個体がある~~ | **無効化された** |
| 公開解の台地がメダルラインを塞いでいない(Biohub は塞いでいる) | 有効 |
| 問題クラスが NEDO のループと一致し、インフラが揃っている | 有効 |
| 相手の replay が公開されており、上位の方策を直接観測できる | **有効(今回むしろ強まった)** |
| ドーマント層 3,000チーム超が分母をかさ上げしている | 有効 |

Biohub 側の評価(公開解の台地を 0.126 下から超える必要、GPU 1枚、残り26日)は変わらないため、
**2つのコンペの相対順位は維持される。**ただし絶対的な期待値は大きく下がった。
