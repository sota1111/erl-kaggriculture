## 2543.4 の出所と、その限界

- **出所:** Kaggle の提出履歴 API が返す submission `55211714` の `publicScore`。
- **同一性の検証:** `kaggriculture-claude` の git 履歴で `main.py` の sha256 を全コミット追跡した。
  08-03 12:33 のコミット SOT-2368 で `main.py` が `7c5a4a2a`(198行)になり、**その1分後の提出**。
  18:21 に soil(`00e8ab59`、332行)へ差し替わり、19:47 の提出が 2089.9、19:53 に moon-198 へ revert。
  → 2543.4 は今回再提出したバイト列そのものの値である。
- **限界1:** 2543.4 は**その提出が非アクティブ化された時点で凍結されたレーティング**であり、
  54 エピソードで収束していたのか、登る途中で止められたのかは記録にない。
- **限界2:** レーティングは相対値である。**「2543.4 は現在の盤面で 165位=銀圏」という対応づけは、
  8月のレーティングを9月の分布に載せたものであり、スケールの時間的安定性を仮定している。**
  この仮定は未検証であり、参戦判断(`docs/decision_2026-09-03.md`)の最も弱い接続部である。
  **本再提出はこの仮定を検証するために出したものであり、銅ライン 1957.2 を超えるかは未確定。**

## 判定規則(事前確定)

- 54 エピソード相当(投入から約 3.5 時間)までは**収束したと言わない**。
- 54 エピソードを超えて上昇が止まった値を収束値とし、ラウンド1 の親スコアとする。
- **収束値が 1957.2(銅ライン)を下回った場合**、2543.4 は現フィールドに対して再現しないと結論し、
  参戦判断の前提そのものを見直す。
